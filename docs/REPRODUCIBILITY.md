# Reproducibility

This document records everything needed to regenerate the results of the
paper bit-for-bit (up to GPU non-determinism, see below).

## 1. Environment used for the reported results

| Component | Version |
|---|---|
| OS | Windows 11, Git-Bash |
| GPU | NVIDIA RTX 3060 (12 GB) |
| CPU / RAM | 16 logical cores / 32 GB |
| Python | 3.13.5 |
| PyTorch | 2.7.1 + CUDA 11.8 |
| NumPy / scikit-learn / pandas | 2.4.3 / 1.7.0 / 2.3.0 |
| wfdb | 4.3.0 |

`qts.utils.environment_info()` (package versions, GPU, cuDNN) and the full
resolved configuration are written to `results/<experiment>/run_info.json`, so
the exact environment travels with the results.

## 2. Data

* **PTB-XL v1.0.3**, 500 Hz records (`records500/`). A record is *normal*
  iff all its diagnostic super-classes are `NORM`. 21,799 records, 18,869
  patients, 9,069 normal / 12,730 abnormal.
* **CPSC 2018** training set (6,877 records). A record is *normal* iff its only
  diagnosis is Normal. Each record is treated as its own patient
  (no patient identifiers are distributed). 918 normal / 5,959 abnormal
  (abnormal : normal ≈ 6.5 : 1).

Preprocessing (`qts/data/preprocessing.py`): 4th-order Butterworth band-pass
0.5–45 Hz applied forward-backward (`scipy.signal.filtfilt`), truncation or
zero-padding to 5,000 samples, per-lead z-score. `prepare_data.py` writes the
SHA-256 of each array to `prepare_info.json`:

| File | SHA-256 |
|---|---|
| cpsc2018/signals.npy | `b2ebfb43b4e5e89f16a68a9e27921df4325237cc95a54767b5e1aa56ac060b53` |
| cpsc2018/labels.npy | `9584625b5c631ccfd2c65d3b7098b7c5896a10fd946de7d72325f3046a53a557` |
| cpsc2018/patient_ids.npy | `ee0e811b414b2d11b848195f4bf1fca9167a115279080c51ec20118e6e13f1ff` |
| ptbxl/* | see `data/processed/ptbxl/prepare_info.json` |

## 3. Splits and seeds

`qts.data.splits.patient_level_split` splits the sorted unique patient IDs
with two calls to `sklearn.model_selection.train_test_split(random_state=seed)`
into 70 % train, 15 % validation and 15 % test patients. Abnormal records are removed from train and validation.
The test set keeps all records of test patients.

The ten seeds `0, 1, …, 9` were fixed before any experiment was run and are
used for every method, dataset and experiment. Within a run the RNG sequence is:
`set_seed(seed)` → build data loaders → build model → `set_seed(seed)` →
move to device → data-driven initialisation (QTS) → training.

## 4. Training protocol (all deep methods)

| Setting | Value |
|---|---|
| Optimiser | AdamW, weight decay 1e-5 |
| Schedule | cosine annealing, T_max = 100 epochs |
| Epochs | ≤ 100, early stopping on validation loss (patience 10, min Δ 1e-4) |
| Gradient clipping | 1.0 (global norm) |
| Batch size | 64 (32 for TranAD and Anomaly Transformer) |
| Model selection | weights of the best validation epoch |

Method-specific settings (learning rates, architecture sizes) are in
`configs/methods.yaml`. QTS: M = 64, K = 155, stride 4, lr 1e-2,
η_min 1e-4, initialised from 256 training records.

Classical baselines use 288 hand-crafted features per record
(`qts/engine/classical.py`): OC-SVM (RBF, ν = 0.1), Isolation Forest (200 trees).

## 5. Metrics and statistics

* AUROC and AUPRC (`sklearn.metrics`), abnormal = positive class.
* Best-threshold F1 over the precision–recall curve. Because abnormal records
  are the majority, the trivial "predict everything abnormal" classifier
  already reaches F1 ≈ 0.73 (PTB-XL) and ≈ 0.92 (CPSC 2018); this value is
  stored as `f1_trivial` in every `metrics.json`.
* Seed-level aggregation: mean ± sample standard deviation (ddof = 1).
* QTS vs. baseline: paired over seeds; mean difference with 95 % t-interval,
  win / tie / loss counts, two-sided Wilcoxon signed-rank test, Holm
  correction across the 12 baselines (`qts/evaluation/stats.py`).

## 6. Additional experiments

* **Template-length ablation** (`configs/ablation.yaml`): K ∈ {35, 155, 315}
  and three multi-scale aggregations, identical protocol and seeds to the main
  benchmark; K = 155 is the main-table QTS run.
* **Cross-dataset transfer** (`scripts/run_transfer.py`): the checkpoint trained
  on the source dataset with seed *s* is evaluated on the *test split* of the
  target dataset generated by the same seed *s*, so in-domain and transfer
  numbers are computed on identical records.
* **Sub-groups** (`scripts/run_subgroup.py`): AUROC of normal test records vs.
  test records carrying a given diagnosis (PTB-XL super-classes; CPSC 2018
  classes), computed from the saved benchmark scores; groups with fewer than 5
  test records are skipped.

## 7. Determinism

cuDNN convolutions are run with `torch.backends.cudnn.deterministic = True`
and `benchmark = False`. Some CUDA kernels (e.g. `index_add`, LSTM backward)
remain non-deterministic; repeated runs therefore agree to about 1e-4 AUROC.
Classical methods and preprocessing are fully deterministic.
